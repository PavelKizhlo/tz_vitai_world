     Скролл-анимации лендинга «Кварта»

     Context

     Лендинг сейчас статичный по структуре: ряды-сетки .ruled (линии = gap: 1px
     на фоне --color-rule), немного CSS scroll-driven эффектов (anim-spin,
     anim-slide, anim-track-in, rise в Wordmark), которые не работают в Firefox.
     Нужно: hero на весь вьюпорт с крупной моделью, ряды ≈ на экран, ячейки
     въезжают вдоль линий сетки (предыдущий ряд в это время чуть уезжает), линии
     сетки прорисовываются по мере скролла, параллакс, переворот букв Wordmark
     (пустой квадрат → квадрат с буквой). Дополнительно согласовано: 3D-пачка
     «перелетает» из hero в карточку Эфиопии, reveal заголовков по строкам,
     плавный скролл Lenis.

     Решения пользователя: ячейки въезжают по осям (без pin), GSAP +
     ScrollTrigger, ряды ≈ 100svh на десктопе/планшете, на мобильном — по
     контенту.

     Архитектура

     Секции остаются серверными компонентами. Вся анимация — в одном клиентском
     компоненте, который находит элементы по data-атрибутам. Без анимаций
     (reduced motion, data-motion="off" из ThemePanel, нет JS) страница выглядит
     как сейчас: линии статичные, буквы видны, модели в своих слотах.

     Зависимости: gsap (SplitText и ScrollTrigger входят бесплатно), @gsap/react
     (useGSAP), lenis. Точные версии — npm view при установке.

     Новая папка src/components/Motion/:
     - gsap.ts — gsap.registerPlugin(ScrollTrigger, SplitText, useGSAP), общие
       константы (смещения, ease).
     - SmoothScroll.tsx — Lenis только при включённых анимациях и fine pointer;
       связка lenis.on("scroll", ScrollTrigger.update), gsap.ticker.add(t => 
       lenis.raf(t * 1000)), lagSmoothing(0); anchors: { offset: -header } для
       якорных ссылок; при выключении — destroy(). В globals.css: html.lenis { 
       scroll-behavior: auto }.
     - ScrollScenes.tsx — один useGSAP, внутри gsap.matchMedia() по брейкпоинтам
       (768/1024). Перестраивается при смене useMotionMode()
       (src/components/Product3D/motion.ts — переиспользуем, перенести в
       Motion/motion.ts и обновить импорт в Product3D/Scene). Сцены:
       a. Линии сетки — для каждого контейнера [data-grid] создаёт оверлей <div 
          class="grid-lines" aria-hidden> с отрезками в зазорах: горизонтальный
          над ячейкой, если она не в первой строке; вертикальный слева, если не
          в первой колонке; плюс нижняя линия контейнера. Координаты — по
          offsetTop/Left (без учёта transform). Ставит контейнеру data-lines,
          CSS тогда заменяет фон-линию на --color-bg и прячет border-bottom.
          Отрезки: scaleX/scaleY 0→1 (горизонтальные слева направо, вертикальные
          сверху вниз), scrub на top 90% → top 40%. Оверлей удаляется в cleanup
          контекста.
       b. Въезд ячеек — прямые дети [data-grid]: направление по колонке (первая
          — слева xPercent: -40, последняя — справа +40, средние/одна колонка —
          снизу yPercent: 30), opacity 0→1, scrub по входу ряда. Контейнер
          overflow: clip, чтобы ячейки «выходили из-за линии». Выход ряда
          (bottom 60% → bottom 0%): лёгкий сдвиг xPercent ±8 в обратную сторону
          — «замещение». Переопределение направления —
          data-from="left|right|up".
       c. Параллакс — [data-parallax="0.2"]: yPercent по прохождению секции.
          Анимировать через CSS-свойство translate (custom property --parallax),
          чтобы не конфликтовать с CSS-анимациями transform у Shape/Waves.
          Цели: Waves в hero/каталоге/«О нас», декоративные Shape, фото в «О
          нас» (сдвиг внутри рамки), текст hero при уходе вверх.
       d. Заголовки — [data-split]: SplitText.create(el, { type: "lines", mask: 
          "lines", autoSplit: true, onSplit }), строки yPercent 100→0 со
          stagger; hero h1 — по загрузке, остальные — по входу. Убрать
          anim-track-in у этих заголовков.
       e. Wordmark — [data-flip]: rotationY 0→180 со stagger по скроллу.
       f. Hero-интро — по загрузке: линии, ячейки, h1, модель.
       g. Перелёт модели (≥768px) — см. ниже.
       - Пересборка при ресайзе по ширине (debounce) и ScrollTrigger.refresh()
         после document.fonts.ready.

     Перелёт 3D-пачки

     - Новый src/components/Motion/FlightProduct.tsx: FlightSlot (клиентский,
       принимает id: "hero" | "catalog" и className) и FlightLayer.
     - Когда перелёт выключен (мобильный / motion off) — каждый FlightSlot
