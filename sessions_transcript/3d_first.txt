     2. Подготовка моделей (скрипты в scratchpad, не в проекте)

       при необходимости center. Результат положить в public/models/bag.glb и
       public/models/box.glb.

     3. Этикетки: public/textures/*.svg

     - Пачки: bag-ethiopia.svg, bag-colombia.svg, bag-brazil.svg. Коробка:
       box-drip.svg.
     - Раскладка повторяет UV-атлас модели. Контент:
       - логотип «КВАРТА»;
       - название, регион и ноты из src/data/catalog.ts;
       - «250 г», дата обжарки и рукописная подпись (стиль Caveat);
       - декоративные формы, как у Shape.
     - Цвета берутся из токенов globals.css (surface, coral, sage, ochre, denim,
       dusty-blue), у каждого сорта свой акцент. Без глянца, радиусы до 5px —
       по README.
     - Шрифты в SVG-текстуре через <img> не подгружаются. Поэтому весь текст
       переводится в кривые: шрифты Unbounded, Onest и Caveat берутся из
       node_modules/next/dist/... или Google Fonts, скрипт конвертирует их через
       opentype.js в scratchpad. Если это окажется слишком сложно, запасной
       вариант — растеризовать SVG в PNG через sharp (он уже есть в
       node_modules). Финальные текстуры — PNG 1024–2048px, если SVG не
       сработает.

     4. Компоненты: src/components/Product3D/

     - Product3D.tsx ("use client") — обёртка вместо Photo. Пропсы: model: "bag"
       | "box", texture, caption (уходит в aria-label), className.
       - Рендерит <div role="img"> с теми же размерами/aspect-ratio, что были у
         Photo.
       - Внутри — dynamic(() => import("./Scene"), { ssr: false }).
       - Пока сцена грузится, показывается fallback — нынешний Photo, чтобы не
         было скачка вёрстки.
     - Scene.tsx:
       - <Canvas dpr={[1, 2]} gl={{ alpha: true, antialias: true }}> с
         прозрачным фоном, чтобы были видны цветные подложки и Shape;
       - мягкий свет: ambientLight и directionalLight, без теней (по README);
       - useGLTF загружает модель, useTexture — этикетку. Для текстуры: flipY = 
         false, colorSpace = SRGBColorSpace. Её кладём в material.map
         клонированного материала с roughness около 0.8, чтобы бумага была
         матовой.
       - модель вписывается в кадр через <Bounds fit> или ручной расчёт по bbox.
     - useMotionPrefs.ts:
       - отслеживает prefers-reduced-motion и data-motion="off" на <html> (тот
         же механизм, что у ThemePanel, через MutationObserver);
       - отслеживает (hover: hover) and (pointer: fine), чтобы понять, десктоп
         ли это.
     - Анимация в useFrame:
       - Покачивание: position.y = sin(t·ω)·A и лёгкий rotation.z, период около
         --motion-bob (5s). У каждого экземпляра своя фаза, чтобы пачки не
         двигались синхронно.
       - Курсор: глобальный pointermove на window. Для каждой сцены считается
         вектор от центра её canvas до курсора, нормализуется и ограничивается
         углом ±25° по Y и ±12° по X. Поворот плавно догоняет цель через
         MathUtils.damp. Когда курсор покидает окно, модель возвращается в
         исходное положение. На тач-устройствах есть только покачивание.
       - При reduced-motion или data-motion="off" модель стоит в статичном
         ракурсе (лёгкий поворот на 3/4), frameloop="demand".
     - Производительность:
       - IntersectionObserver переключает frameloop между "always" и "never",
         когда canvas уходит за экран;
       - useGLTF.preload для обеих моделей;
       - одна .glb на все три пачки (кеш drei).
